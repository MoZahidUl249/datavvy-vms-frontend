  • Sidebar is for places only. “Register vehicle” moved out of it; it's an action, so it lives on the page.
  • One item, Vehicles, with a live count badge.
  • New breadcrumb bar on top of every screen: Vehicles › DHA-METRO-GA 11-4582.
  • Every item is 44 px tall.

  • Three sizes: 44 px page actions, 36 px toolbar and row actions, 36 px icon buttons with tooltips.

6 · Loading states
  • Placeholder rows take the exact shape of real rows (two lines, status pill), so nothing shifts when data arrives.
  • Header, filters and search stay usable while rows load.
  • Soft shimmer instead of blinking; it stops for people who turn on reduced motion.
  • Saving locks the form fields and shows a spinner in the button.
  • Try different load times with Tweaks › loadDelay.
7 · Validation messages
  • Errors appear when you leave a field or press Save, never while you're still typing. They disappear as soon as the field is fixed.
  • Exception: a duplicate number shows right away, with “Open that vehicle”.
  • Every message says how to fix it, with an example (“like Toyota”).
  • Icon + red text + red border, so the error doesn't rely on colour alone. Screen readers read it from the field.
  • On Save, a summary at the top lists each problem as a link that jumps to the field.
